Cara Menjalankan

Pastikan Python 3 sudah terinstal, lalu buka terminal di folder tugas ini.

bash
# (opsional) buat dan aktifkan virtual environment
python3 -m venv venv
source venv/bin/activate

# jalankan salah satu file, contoh:
python3 hello.py

Khusus materi module, jalankan dari dalam foldernya:

bash
cd module
python3 main.py

Untuk mengecek environment, jalankan python3 test_env.py.
